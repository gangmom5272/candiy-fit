# CANDiY-FiT · 캔디핏

**웨어러블 데이터 기반 AI 코칭 서비스**

웨어러블 기기로 기록한 건강데이터를 차트로 확인하고, AI 코치에게 질문하며 자신의 생활 습관을 돌아볼 수 있는 서비스입니다. AI 답변과 함께 분석에 사용한 기간·지표·수치를 제공해, 사용자가 코칭의 근거를 직접 확인할 수 있도록 했습니다.

- 개발 기간: 2026.10.06 ~ 2026.11.18
- 팀 구성: 6명 (Backend 2 · Frontend 2 · AI 1 · Data/Infra 1)

## 서비스 구성

| 구성 | 설명 |
| --- | --- |
| CANDiY-LiNK | 휴대폰의 건강 기록을 CANDiY SDK와 연동하는 Android 수집 앱 |
| CANDiY-FiT | 건강 지표 대시보드와 AI 코칭 대화를 제공하는 웹 서비스 |

## 주요 기능

- **건강데이터 연동**: 걸음 수·심박수·산소포화도·수면·운동 등 건강 기록을 수집하고 조회합니다.
- **건강 지표 시각화**: 기간별 지표와 변화 추이를 차트로 확인합니다.
- **AI 코칭 대화**: 건강데이터에 대해 질문하고, 조회한 기록을 바탕으로 생활 습관 코칭을 받습니다.
- **답변 근거 제공**: 답변에 활용한 데이터의 기간·지표·수치를 함께 표시합니다.
- **스트리밍 응답**: WebSocket으로 답변과 진행 상태를 전달합니다.
- **사용자별 접근 제어**: 인증된 사용자가 본인의 건강데이터와 대화 이력에 접근하도록 합니다.

## 데이터 처리와 코칭

1. Android 앱이 CANDiY SDK를 통해 건강 기록을 전송합니다.
2. 데이터 파이프라인이 CANDiY API로 기록을 조회하고, 원본 적재·중복 처리·결측 및 이상치 처리·일별 집계를 수행합니다.
3. 사용자가 웹에서 질문하면 코칭 에이전트가 필요한 건강데이터를 조회하고 LLM으로 답변을 생성합니다.
4. 웹은 응답을 스트리밍으로 표시하고, 근거 데이터와 차트를 함께 보여 줍니다.

건강 지표의 계산과 비교는 규칙에 따라 처리하고, LLM은 조회·계산한 결과를 바탕으로 설명을 생성합니다. 코칭은 생활 습관 이해를 돕는 용도이며, 의료적 진단이나 처방을 제공하지 않습니다.

## 개발 및 시연용 합성 데이터

개발 및 시연에 사용하는 합성 데이터는 **CANDiY API의 데이터 구조를 참고하여 가상의 페르소나를 기반으로 생성**했습니다.

- 실제 사용자의 개인정보 및 건강정보를 포함하지 않습니다.
- 실제 사용자 데이터를 익명화한 데이터가 아닙니다.
- 페르소나별 생활 패턴과 결측·이상치 등 다양한 상황을 재현하기 위해 만들었습니다.

## 실행 시 필요한 외부 구성

CANDiY SDK 원본과 API·LLM 인증 정보는 별도로 준비해야 합니다. 공개 코드만으로 실제 건강데이터 수집과 전체 서비스를 바로 실행할 수 있는 구성은 아닙니다.

실제 인증키와 환경 변수 파일, 실제 사용자 건강데이터, 비공개 SDK 원본은 공개 대상에 포함하지 않습니다.
