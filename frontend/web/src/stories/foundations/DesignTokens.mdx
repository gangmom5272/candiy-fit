export const cssVar = (name) => (el) => {
	if (el) {
		const value = getComputedStyle(document.documentElement).getPropertyValue(name).trim();
		el.textContent = name.startsWith('--color-') ? value.toUpperCase() : value;
	}
};

export const Swatch = ({ surface, text, label = 'Aa', outline }) => (
	<div
		style={{
			width: 72,
			maxWidth: '100%',
			height: 32,
			borderRadius: 8,
			display: 'flex',
			alignItems: 'center',
			justifyContent: 'center',
			fontFamily: 'var(--font-sans)',
			fontSize: 14,
			background: `var(--color-${surface})`,
			color: `var(--color-${text})`,
			border: '1px solid var(--color-border)',
			outline: outline ? `2px solid var(--color-${outline})` : undefined,
			outlineOffset: outline ? 2 : undefined
		}}
	>
		{label}
	</div>
);

# Design Tokens

CANDiY-FiT Web의 현재 색상·형태·글자 기준을 한곳에서 확인한다.
기준 문서는 `docs/design-system.md`, 서비스 토큰과 역할 유틸리티는 `src/routes/layout.css`다.

### 사용 및 접근성 기준

- 같은 의미의 색에 다른 HEX를 만들지 않는다. 반복되는 arbitrary value는 토큰 또는 공통 스타일로 정리한다.
- Kakao·Google 등 외부 브랜드 색은 서비스 의미 토큰과 별도로 관리한다.
- 상태는 색만으로 구분하지 않고 글자·아이콘을 함께 사용한다.
- **비선택과 비활성은 다르다.** 읽어야 하는 설명·오류·결측 안내·비선택 메뉴·placeholder에는 `text-text-disabled`를 쓰지 않는다.
- 보조 글자 `text-muted-foreground`는 페이지 배경(4.61:1)과 카드(4.77:1)에서 사용한다. 연한 muted·accent·coral 배경에서는 일반 글자에 `text-foreground`를 사용한다.
- `primary` 위 `primary-foreground` 대비는 4.76:1, 버튼 hover인 `primary-hover` 위에서는 5.67:1이다.
- `brand` 위 밝은 글자는 약 3.03:1이다. 작은 본문에 쓰지 않고 장식·아이콘·큰 글자에 사용한다. 큰 글자 기준은 일반 24px 이상 또는 굵게 18.66px 이상이다.
- 실제 비활성 버튼의 `primary-light` 배경은 비활성 UI의 대비 예외로 유지한다. 일반 글자는 4.5:1, 큰 글자·비텍스트 정보는 3:1 기준을 확인한다.
- 색상 대비는 `src/routes/color-contrast.spec.ts`, 토큰 참조 관계는 `src/routes/theme-alias.spec.ts`가 검사한다.

```html
<div class="bg-card text-card-foreground">카드와 그 위 글자</div>
<div class="bg-muted text-foreground">연한 보조 배경 위 일반 글자</div>
<button class="bg-primary text-primary-foreground hover:bg-primary-hover">주요 동작</button>
```

### Radius 기준과 현재 유틸리티

4의 배수인 4·8·12·16px을 우선하고, 필요한 예외는 2·6px 같은 짝수를 사용한다.
같은 역할의 컴포넌트에는 같은 radius를 적용한다. Tailwind 기본 단계를 사용하며 shadcn의 `--radius` 계산식은 사용하지 않는다.
기존 Figma에 확정된 다른 값은 유지하고, 이 표에 맞추기 위한 서비스 UI 일괄 변경은 하지 않는다.

### Shadow 기준과 실제 예시

프로젝트 기준은 X / Y / Blur가 **2 / 2 / 2 또는 0 / 2 / 2px**, Spread는 **0**이다.
색상·opacity는 확정 Figma를 우선하고, 같은 역할의 card·floating UI에는 같은 기준을 적용한다.
프로젝트 공통 shadow 색상·opacity와 전용 토큰은 아직 확정되지 않았으므로 임의의 새 값을 기준으로 지정하지 않는다.

아래는 **현재 Tailwind 기본 shadow 유틸리티**의 값과 예시다. 위 프로젝트 offset 기준과 동일하다는 뜻은 아니며, 기존 화면의 확정 shadow를 이 예시로 일괄 바꾸지 않는다.

### Font Family와 굵기

`font-sans`의 실제 값은 <code ref={cssVar('--font-sans')} />다. Paperlogy는 weight별로 family를 나누지 않는다.
WOFF2 9개는 Thin(100) · ExtraLight(200) · Light(300) · Regular(400) · Medium(500) · SemiBold(600) · Bold(700) · ExtraBold(800) · Black(900)으로 등록되어 있다.
`font-style: normal`, `font-display: swap`이며 주로 `font-normal`(400)·`font-medium`(500)·`font-semibold`(600)·`font-bold`(700)를 사용한다. 라이선스는 `static/Paperlogy-OFL.txt`다.
